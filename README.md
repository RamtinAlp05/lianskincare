
# LianSkinCare

A centralized multi-brand skincare e-commerce platform.

## Project Overview

LianSkinCare is an educational portfolio project focused on building a centralized skincare e-commerce platform.

The platform provides products from multiple skincare brands through a single store with centralized inventory, order management, and checkout.

## Technology Stack

### Frontend
- Next.js
- TypeScript

### Backend
- FastAPI
- Python 3.12
- SQLAlchemy 2
- Alembic
- Pydantic Settings

### Database
- PostgreSQL

## Architecture

Modular Monolith with Clean Architecture principles where appropriate.

## Development Status

Currently in the Backend Foundation phase.

## Scope

- User authentication and management
- Product catalog and variants
- Shopping cart and inventory
- Checkout and order management
- Product reviews and ratings
- Rule-based recommendations

## Project Constraints

- Centralized store, not a marketplace
- One centralized warehouse
- Mock payment and shipping services
- USD currency
- English user interface
